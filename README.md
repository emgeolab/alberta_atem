# Calgary-Lethbridge Corridor Geophysical Survey (ATEM)

In February and March 2011, Aeroquest Airborne Surveys collected 27,000 km of
airborne time domain- electromagnetic (AEM) data in southern Alberta. The data
were collected for Alberta Environment (AENV) as part of Alberta’s Provincial
Groundwater Inventory Program (PGIP). The purpose of the survey was to map
aquifers with EM techniques.
